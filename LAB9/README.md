# LAB9 — Named Entity Recognition (NER)

## Overview
Use spaCy to identify entities, add custom entity patterns, and train a small NER model.

## Completed Tasks
- Task 1: Read a user sentence and print its named entities and details.
- Task 2: Add company/person names in a legal paragraph, count PERSON/ORG, and visualize entities.
- Task 3: Train a custom spaCy NER model for 20 iterations, save it in `custom_ner_model`, and load it again.

## Files
- `Lab9_Named_Entity_Recognition.ipynb`

## Run
Use Jupyter or Colab with `spacy` and its `en_core_web_sm` model. The folder `custom_ner_model` is generated when Task 3 is run; it is not committed here. Task 1 asks for interactive input.
