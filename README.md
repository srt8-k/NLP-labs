# NLP Labs

This repository contains my completed Natural Language Processing lab work, organized into separate folders for each lab.

## Repository Structure

| Lab | Topic | Main Work |
|---|---|---|
| [LAB1](./LAB1) | Introduction to NLP | Dataset selection, download, loading, and basic exploration |
| [LAB2](./LAB2) | Text Preprocessing & Regular Expressions | Hashtag analysis, regex, spaCy and NLTK tokenization |
| [LAB3](./LAB3) | N-gram Language Models | Tweet preprocessing, bigram MLE, probability and perplexity |
| [LAB4](./LAB4) | Classification & Evaluation | Text preprocessing, TF-IDF, Naive Bayes, evaluation and confusion matrix |
| [LAB5](./LAB5) | Text Representation | Cosine similarity, TF-IDF and Word2Vec |
| [LAB6](./LAB6) | Deep Learning for NLP | TF-IDF/Word2Vec representations and PyTorch neural networks |
| [LAB7](./LAB7) | Large Language Models | Transformer families, sentiment classification and summarization |

## Tools and Libraries

The notebooks use Python and common NLP / machine-learning libraries, including:

- pandas
- NumPy
- NLTK
- spaCy
- scikit-learn
- gensim
- PyTorch
- Hugging Face Transformers
- kagglehub

## Running the Labs

The notebooks are designed to run in Jupyter Notebook or Google Colab. Some labs download public datasets or model files at runtime, so an internet connection may be required.

Open the required lab folder, run the notebook from top to bottom, and install any package requested by the notebook if it is not already available.

## Dataset Note

Small datasets are included in the repository when practical. Larger public datasets are downloaded at runtime to avoid unnecessarily storing large files in the repository.
