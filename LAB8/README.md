# LAB8 — Part-of-Speech (POS) Tagging

## Overview
Practice POS tagging using NLTK and spaCy.

## Completed Tasks
- Task 1: Find the coarse and fine-grained POS tags for "play" and explain the tags.
- Task 2: Compare Google/google and table used as a noun or verb.
- Task 3: Visualize the sentence dependencies with displaCy.

## Files
- `Lab8_Part_of_Speech_(POS).ipynb`

## Run
Use Jupyter or Colab. Install `nltk` and `spacy` if needed. The notebook downloads the required English tagging resources/model when missing.
