# LAB1 — Introduction to Natural Language Processing

## Overview

This lab introduces the NLP working environment and basic dataset handling. The assignment asks students to choose a dataset type, download a dataset, open it, and inspect its contents.

## Completed Work

For this lab, I selected the **IMDB Movie Reviews** CSV dataset and used `kagglehub` to download it.

The notebook includes:

- Downloading the dataset from Kaggle
- Loading the CSV file with pandas
- Displaying the dataset shape and sample rows
- Exploring dataset statistics and column information
- Checking the sentiment class distribution
- Printing an example review and its sentiment
