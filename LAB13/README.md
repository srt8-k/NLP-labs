# LAB13 — Information Retrieval for RAG

## Overview
In this lab we use TF-IDF and cosine similarity to search a small group of NLP notes.

## Completed Exercises
- Part 1: Search for Named Entity Recognition and compare k=1 with k=3.
- Part 2: Search for NER, add a document about BERT, rebuild the TF-IDF matrix and search again.

## Files
- `Lab_13_Part_1_Information_Retrieval_for_RAG.ipynb`
- `Lab_13_Part_2_Search_and_Retrieval.ipynb`

## Run
Open either notebook in Jupyter or Google Colab and run all cells. These examples use `scikit-learn` and do not need any external dataset.
