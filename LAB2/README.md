# LAB2 — Text Preprocessing & Regular Expressions

## Overview

This lab focuses on preparing raw text for NLP tasks and using regular expressions for text matching and manipulation.

## Completed Tasks

### Task 1 — Hashtag Analysis
- Download the Apple Twitter Sentiment dataset
- Extract hashtags from tweets
- Count the total number of hashtags
- Display the top 10 most frequent hashtags

### Task 2 — `re.compile()`
- Compile a digit-matching regular expression
- Display the compiled pattern type
- Replace `2021` with `2022`
- Explain why compiled regex patterns are useful

### Task 3 — `re.split()`
- Split a string whenever one or more digits appear
- Display the resulting list
- Explain the purpose of `re.split()`

### Task 4 — Tokenization
- Tokenize a sentence using spaCy
- Tokenize the same sentence using NLTK
- Compare the tokenization behavior
- Explain what `spacy.load()` does
