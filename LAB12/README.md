# LAB12 — Transformers

## Overview
This lab introduces Transformers and self-attention using DistilBERT and BERT.

## Completed Task
- Load `bert-base-uncased`.
- Print the number of Transformer layers and attention heads per layer.
- Calculate the total number of attention heads.
- Extract the attention matrix from the third layer and second head for the given sentence.
- Show the attention matrix and explain what its rows and columns represent.

## Files
- `Lab12_Transformers.ipynb` — completed notebook with saved outputs after running

## Run
Open the notebook in Jupyter or Google Colab and use Run All. The pretrained models are downloaded from Hugging Face, so an internet connection is needed the first time.
